# User Authentication & JWT

A full-stack user authentication application built using Node.js, Express, SQLite, bcrypt, and JSON Web Tokens (JWT).

## Features

- User registration
- Password hashing using bcrypt
- User login
- JWT-based authentication
- HTTP-only cookie for secure token storage
- Protected API route
- JWT verification middleware
- User logout
- SQLite database
- Postman API collection

## Technologies Used

- Node.js
- Express.js
- SQLite
- bcrypt
- JSON Web Token (JWT)
- Cookie Parser
- HTML
- CSS
- JavaScript
